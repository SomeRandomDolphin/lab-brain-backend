# Works on Windows, macOS, and Linux — no system-level audio library needed.

# NOTE: pyaudio is NOT required for this PoC.
# Mic capture happens entirely in the browser via the Web Audio API.
# The server only receives raw PCM over WebSocket — no OS audio driver needed.

# If you later want server-side mic capture (e.g. for a CLI recording tool),
# use sounddevice instead of pyaudio — it works on Windows without extra setup:
#   pip install sounddevice
# sounddevice bundles its own PortAudio binary on Windows/macOS via the wheel,
# so no separate apt/brew/choco install is required.
